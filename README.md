# java-console-contact-manager

A simple **console-based Contact Manager built with Java** for practicing Collections, OOP, and CRUD operations using `ArrayList`.

## Features

* Add contact
* View all contacts
* Search contact
* Update contact
* Delete contact
* Clear screen
* Exit application

## Concepts Practiced

* Classes and Objects
* Encapsulation
* Constructors
* Getters and Setters
* `ArrayList`
* CRUD operations
* `Scanner`
* Loops
* `switch`
* Methods
* Basic multi-file Java project structure

## Project Structure

```text
ContactManager/
│
├── Contact.java
└── ContactManager.java
```

## Contact Details

Each contact contains:

```text
ID
Name
Phone
Email
```

## How to Run

Compile the project:

```bash
javac Contact.java ContactManager.java
```

Run the application:

```bash
java ContactManager
```

## Example

```text
===== CONTACT MANAGER =====

1. Add Contact
2. View Contacts
3. Search Contact
4. Update Contact
5. Delete Contact
6. Clear Screen
7. Exit

Enter your choice:
```

## Purpose

This project was created as a **Java practice project** to understand how `ArrayList` can be used to store and manage multiple objects while implementing basic CRUD operations.

## Limitations

* Data is stored only in memory.
* Data is lost when the program closes.
* No database or file storage is used.
* Input validation is basic.

## Technologies

* Java
* `ArrayList`
